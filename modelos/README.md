# Modelos de arte do Canal GOAT

Coloque aqui artes que a equipe de arte deve usar como **referência** (PNG ou JPG), uma pasta por tipo de peça:

| Pasta | Peça |
|---|---|
| `agenda-do-dia/` | Agenda do dia (feed) |
| `jogo-unico/` | Agenda de jogo único |
| `manchete/` | Manchete / notícia |
| `chamada/` | Chamada de jogo |
| `estatisticas/` | Números, ranking, comparação |
| `carrossel/` | Carrossel (uma imagem por slide: `nome-1.png`, `nome-2.png`…) |
| `story/` | Stories e enquetes |
| `tarja-video/` | Tarjas e aspas para vídeo |
| `outros/` | Qualquer outra peça |

Dica: no nome do arquivo, diga o que ele mostra de bom (ex.: `agenda-3-jogos-foto-grande.png`).

Antes de montar uma peça, os designers abrem os modelos da pasta correspondente e seguem o mesmo padrão
(sempre junto com a skill `canal-goat-artes`). Se um modelo pedir um layout que o kit ainda não monta,
o designer avisa o CEO no card (ex.: "modelo novo de carrossel: precisa entrar no kit").
